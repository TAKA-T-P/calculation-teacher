## 読み取り方法と注意点

- 3つのPDFはどれも、数式が画像のように描かれていて、**テキスト抽出では内容を読み取れませんでした**（抽出結果は空白とページ番号だけ）。
- そのため、全ページを画像にして**目視で読み取りました**。節の見出しは全ページ分を一覧にして確認しました。解説の途中式は、代表的なページで確認しました。
- 読み取れない問題を推測で使うことはしていません。作った30問は、PDFの問題を写したものではありません。式と数値を変えたオリジナルです。PDFからは「どんな種類の問題があるか」「どの程度の難しさか」「解説でどう式を変形しているか」だけを参考にしました。

## PDFの書き方から決めたこと

- 計算の解説は「元の式 ＝ 途中式 ＝ … ＝ 答え」の形で、2行目以降は `=` で始まります。
  → 答案データでも、式の計算の2行目以降は `=` から始めることにしました（例：`"=-5+8-6"`）。
- 方程式の解説は1行に1つの等式を書き、「両辺に10をかけると」「〜を移項すると」のような説明文を行の間に入れています。
  → 答案の行には数式だけを書き、説明文は `explanation` に入れることにしました。
- 異符号の2数の加法は `=-(7-3)` のように「符号を決めてから絶対値を計算する」形、乗除は `=-(12\div3\times2)` のように「符号を先に決める」形で書かれています。
  → 中1の答案でもこの書き方を使います。

## PDFの内容から整理した典型的な計算ミス

PDFの解説で特に丁寧に書かれている変形（＝生徒がつまずきやすい箇所）をもとに、答案に入れる誤りを整理しました。

### 正負の数
- 異符号の加法で、絶対値の大きいほうの符号をつけ忘れる
- 減法を加法に直すときに、ひく数の符号を変え忘れる（`-(-8)` → `-8`）
- 負の数の個数から積・商の符号を決めるときの誤り
- わる数を逆数にし忘れる（「除法を乗法になおして計算する」）
- 累乗で指数がかかる範囲を読み違える（`-3^2` と `(-3)^2` の混同）
- 負の数の偶数乗の符号の誤り
- 四則計算の順序の誤り（加減を乗除より先に計算する）

### 文字式
- `a\times a` を `2a` とする（指数の誤り）
- 負の数を代入するときに、かっこや累乗の前の負号を正しく処理できない（`-(-4)^2`）
- 項を並べかえるときに符号を変えてしまう
- 同類項をまとめるときに文字をかけてしまう（`5a+3a=8a^2`）
- 分配法則で2つ目の項にかけ忘れる
- かっこの前の負号の処理の誤り（分数の分子の中のかっこでは特に見落としやすい）

### 1次方程式
- 移項するときに符号を変え忘れる
- 両辺を負の数でわるときの符号の誤り
- かっこをはずすときの分配法則のかけ忘れ・負号の処理の誤り
- 小数を整数に直すときに、一部の項だけ10倍している（100倍すべき項など、桁の誤り）
- 分母をはらうときに、分数ではない項に数をかけ忘れる
- 係数でわるときに逆数ではなく係数そのものをかける

### PDFの書き方から決めたこと（中2・中3）

- 式の計算・展開・平方根の解説は、中1と同じく「元の式 ＝ 途中式 ＝ … ＝ 答え」の形です。→ 答案の2行目以降は `=` で始めます。
- 連立方程式の加減法は、2つの式を縦に並べ、`+)`・`-)` と横線を使った筆算の形で書かれています（式には ① ② の番号がつき、「②×3」のように何倍したかが左に書かれています）。→ 筆算1つを答案の1行（`\begin{array}{r}…\end{array}`）にしました。番号や「②×3」は説明文なので、答案には入れず解説に書きます。
- 連立方程式の答えは「よって　x=3，y=−2」の形です。→ 最終行は `x=3,\ y=-2` にしました。
- 2次方程式は「左辺を因数分解すると (x−1)(x−6)=0」「x=0 または x−7=0」「よって x=−5, 6」の形です。→ 各行を方程式にし、「または」の行や `x=5,\ -2` の形の最終行を使えるようにしました。
- 解の公式は「解の公式に a=5, b=7, c=1 を代入すると」のあとに、数を代入した公式の形をそのまま書いています。→ 答案でも `x=\frac{-7\pm\sqrt{7^2-4\times5\times1}}{2\times5}` のように、代入した形の行を入れました。
- 平方根の答えは、根号の中をいちばん小さい自然数にし、分母を有理化した形です。→ 答えの形として自動検証で確かめるようにしました。

### PDFの内容から整理した典型的な計算ミス（中2・中3）

#### 式の計算
- ひく式のかっこをはずすとき、うしろの項の符号を変え忘れる
- 単項式の乗法で、同じ文字の指数をたし忘れる・かけてしまう（`(a^2)^3` を `a^5`）
- わる式が分数の単項式のとき、逆数で文字を分母にしない（`\div\frac{3}{4}ab` を `\times\frac{4}{3}ab`）
- 負の数の累乗の符号（`(-3x)^2`・`(-a^2b)^3`）
- 分数の形の式で、ひく分数の分子の符号を変え忘れる・分母をはらうとき分母のない項にかけ忘れる

#### 連立方程式
- 式どうしをひくとき、うしろの式の負の項の符号を変え忘れる・右辺をたしてしまう
- 式を何倍かするとき、右辺にかけ忘れる
- 代入したあとの移項の符号、負の数を代入するときのかっこのつけ忘れ
- `-y=a` から `y` を求めるときの符号
- 答えを書くときに x と y を取り違える

#### 展開・因数分解
- 平方の公式で 2倍の積の項を忘れる・係数を2乗し忘れる
- `a^2-b^2` と `(a-b)^2` の取り違え
- 和と積の両方を満たす2数を選んでいない（積だけで選ぶ）
- 共通因数をくくり出しただけで終わる（因数分解が不完全）
- おきかえたあと、かっこをはずすときの符号

#### 平方根
- 根号の中の数をたす（`\sqrt3+\sqrt3=\sqrt6`）
- 平方数を、その平方根にせずに根号の外に出す（`\sqrt{50}=25\sqrt2`）
- 有理化で分子に根号をかけ忘れる・`\sqrt a\times\sqrt a` を `a^2` とする
- 有理化したあと約分し忘れる・分子の一部の項だけを約分する

#### 2次方程式
- ゼロ積の法則で解の符号を誤る・解を1つだけ求めて終わる
- `x^2=a` で負の解を忘れる・両辺を x でわって解を失う
- 平方完成で、右辺に同じ数をたし忘れる・± を忘れる
- 解の公式で −b・分母 2a・根号の中 `b^2-4ac` の符号を誤る
- 根号の簡単化のあと、分子の一部の項だけを約分する
