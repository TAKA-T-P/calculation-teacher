# 参考資料（中1 PDF）の分析

第1段階で参考にした3つのPDFの構成と、そこから整理した問題カテゴリ・典型的な計算ミスの記録です。

|---|---|---|
| `問題サンプル/1年①正負の数.pdf` | 55 | 38 |
| `問題サンプル/1年②文字式.pdf` | 36 | 26 |
| `問題サンプル/1年③1次方程式.pdf` | 38 | 19 |

> 指示書では `1-1正負の数.pdf` などのファイル名でしたが、実際のファイル名は上の表のとおりです（内容は同じ単元）。

## 読み取り方法と注意点

- 3つのPDFはどれも、数式が画像のように描かれていて、**テキスト抽出では内容を読み取れませんでした**（抽出結果は空白とページ番号だけ）。
- そのため、全ページを画像にして**目視で読み取りました**。節の見出しは全ページ分を一覧にして確認しました。解説の途中式は、代表的なページで確認しました。
- 読み取れない問題を推測で使うことはしていません。作った30問は、PDFの問題を写したものではありません。式と数値を変えたオリジナルです。PDFからは「どんな種類の問題があるか」「どの程度の難しさか」「解説でどう式を変形しているか」だけを参考にしました。

## PDFの書き方から決めたこと

- 計算の解説は「元の式 ＝ 途中式 ＝ … ＝ 答え」の形で、2行目以降は `=` で始まります。
  → 答案データでも、式の計算の2行目以降は `=` から始めることにしました（例：`"=-5+8-6"`）。
- 方程式の解説は1行に1つの等式を書き、「両辺に10をかけると」「〜を移項すると」のような説明文を行の間に入れています。
  → 答案の行には数式だけを書き、説明文は `explanation` に入れることにしました。
- 異符号の2数の加法は `=-(7-3)` のように「符号を決めてから絶対値を計算する」形、乗除は `=-(12\div3\times2)` のように「符号を先に決める」形で書かれています。
  → 中1の答案でもこの書き方を使います。

## PDFの内容から整理した典型的な計算ミス

PDFの解説で特に丁寧に書かれている変形（＝生徒がつまずきやすい箇所）をもとに、答案に入れる誤りを整理しました。

### 正負の数
- 異符号の加法で、絶対値の大きいほうの符号をつけ忘れる
- 減法を加法に直すときに、ひく数の符号を変え忘れる（`-(-8)` → `-8`）
- 負の数の個数から積・商の符号を決めるときの誤り
- わる数を逆数にし忘れる（「除法を乗法になおして計算する」）
- 累乗で指数がかかる範囲を読み違える（`-3^2` と `(-3)^2` の混同）
- 負の数の偶数乗の符号の誤り
- 四則計算の順序の誤り（加減を乗除より先に計算する）

### 文字式
- `a\times a` を `2a` とする（指数の誤り）
- 負の数を代入するときに、かっこや累乗の前の負号を正しく処理できない（`-(-4)^2`）
- 項を並べかえるときに符号を変えてしまう
- 同類項をまとめるときに文字をかけてしまう（`5a+3a=8a^2`）
- 分配法則で2つ目の項にかけ忘れる
- かっこの前の負号の処理の誤り（分数の分子の中のかっこでは特に見落としやすい）

### 1次方程式
- 移項するときに符号を変え忘れる
- 両辺を負の数でわるときの符号の誤り
- かっこをはずすときの分配法則のかけ忘れ・負号の処理の誤り
- 小数を整数に直すときに、一部の項だけ10倍している（100倍すべき項など、桁の誤り）
- 分母をはらうときに、分数ではない項に数をかけ忘れる
- 係数でわるときに逆数ではなく係数そのものをかける
